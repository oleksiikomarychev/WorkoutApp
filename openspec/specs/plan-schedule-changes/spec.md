# plan-schedule-changes Specification

## Purpose

Определяет гарантии изменения расписания применённого плана, которые защищают историю завершённых тренировок при переносе дат.

## Requirements

### Requirement: Завершённые тренировки не меняются при переносе
Система SHALL оставлять завершённые тренировки неизменными при любой операции переноса расписания, даже если они попадают в выбранный диапазон. Завершённой считается тренировка с заполненным `completed_at` или `status == "completed"`.

#### Scenario: Диапазон содержит завершённую тренировку
- **WHEN** пользователь переносит расписание в диапазоне с завершённой тренировкой
- **THEN** дата, содержимое и результат завершённой тренировки остаются неизменными

#### Scenario: Диапазон содержит завершённые и незавершённые тренировки
- **WHEN** пользователь переносит расписание в диапазоне с завершёнными и незавершёнными тренировками
- **THEN** завершённые тренировки остаются неизменными независимо от результата переноса незавершённых

#### Scenario: Признаки завершения расходятся
- **WHEN** в диапазоне находится тренировка только с одним признаком завершения: заполненным `completed_at` или `status == "completed"`
- **THEN** система не изменяет эту тренировку
