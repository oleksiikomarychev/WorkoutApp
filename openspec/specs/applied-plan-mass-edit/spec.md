# applied-plan-mass-edit Specification

## Purpose

Определяет гарантии массового изменения упражнений и подходов применённого плана: сохранение завершённых тренировок и единый результат всей операции.

## Requirements

### Requirement: Завершённые тренировки не меняются при массовой правке
Система SHALL исключать завершённые тренировки из изменений массовой правки независимо от заданных фильтров. Завершённой считается тренировка с заполненным `completed_at` или `status == "completed"`.

#### Scenario: Выборка содержит завершённую тренировку
- **WHEN** массовая правка выбирает диапазон, в котором есть завершённая тренировка
- **THEN** упражнения, подходы и результаты завершённой тренировки остаются неизменными

#### Scenario: Признаки завершения расходятся
- **WHEN** массовая правка выбирает тренировку только с одним признаком завершения: заполненным `completed_at` или `status == "completed"`
- **THEN** система не изменяет эту тренировку

### Requirement: Полный откат массовой правки при сбое
Система SHALL сохранять изменения массовой правки только при успешном выполнении всех предусмотренных изменений; при сбое любого из них SHALL отменять все изменения этой операции и сообщать о неуспехе.

#### Scenario: Сбой после первого изменения
- **WHEN** первое изменение массовой правки выполнено, а последующее завершается ошибкой
- **THEN** ни одно изменение этой операции не остаётся сохранённым и пользователь получает неуспешный результат

#### Scenario: Полная успешная правка
- **WHEN** все предусмотренные изменения массовой правки завершены успешно
- **THEN** система сохраняет все изменения операции и сообщает об успехе
