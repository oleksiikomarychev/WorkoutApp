AI evals и deployment в данном обзоре не запускались. Число найденных тестов
не является оценкой покрытия. Для agent suite отдельно отмечен риск применения
application DB до изоляции тестового окружения; опасный запуск не выполнялся.

product specs не расширялись этим документационным шагом.
