# EC-20261112-partial-mass-edit: сбой после первой правки подхода

- Статус: fixed
- Область: workouts-service, массовая правка применённого плана
- Класс: partial-failure
- Обнаружен: 2026-11-10; проверен после исправления 2026-11-12
- Связи: ME-3, GAP-5, `plan-operation-contracts`

## Условие и влияние

Первый подход изменён, второе изменение падает. Ранее вспомогательные методы
делали отдельный commit и скрывали ошибку: операция могла оставить часть изменений.
Принятый контракт требует откатить всю операцию.

## Воспроизведение и проверка

Синтетическая тренировка с двумя подходами весом 10 и 20. Массовая правка задаёт
вес 50; тест внедряет ошибку перед изменением второго подхода. После rollback
в новой сессии оба исходных веса должны сохраниться.

Регрессия: `services/workouts-service/tests/test_applied_plan_mass_edit_contract.py::test_failed_second_set_rolls_back_first`.
Из корня: `uv run --package workouts-service pytest services/workouts-service/tests/test_applied_plan_mass_edit_contract.py -q`.
По умолчанию SQLite; `CONTRACT_TEST_POSTGRES_URL` включает PostgreSQL с отдельной
случайной схемой. Схема удаляется после проверки.

До исправления: тест не запускался на исходной версии; дефект установлен чтением
кода, поэтому статус `verified` не присваивается.
После исправления: 2026-11-12, рабочее дерево, тест прошёл на SQLite и PostgreSQL 16.

## Исправление и ограничения

Действия массовой правки используют `commit=False`, а операция фиксирует изменения
одним commit. Ошибки прерывают обработку. Проверен сервис и транзакция; полный
HTTP/Celery E2E ещё не выполнен.
