# Сквозные контракты и анализ влияния change

- Статус: accepted
- Дата: 2026-11-12
- Область: процесс разработки и обсуждения спецификаций
- Кем согласовано: владелец проекта в чате
- Основание: после предложения обзора приложения, общих контрактов и очереди changes владелец поручил «приступай».
- Связи: [каркас](../architecture/README.md), [область влияния](../architecture/change-impact.md)

## Решение

Подготовить карту возможностей всего приложения, проект общих гарантий и очередь
ограниченных изменений OpenSpec. Использовать карту для оценки влияния конкретного
change. Поддерживать различие фактов реализации, согласованных требований и
исполняемых доказательств.

## Границы согласования

Принято направление работы и создание базы процесса. Конкретные шесть семейств,
их продуктовые правила, приоритеты rollout и ответы о supplements/CDC/macros
предложены агентом и ещё не согласованы. Это решение не разрешает автоматически
внедрять новое поведение во всех сервисах.

## Последствия и проверка

Общий процесс остаётся change-oriented: отдельный change меняет ограниченную
область применимости контракта; полное предварительное описание приложения не
требуется. Main specs обновляются после соответствующей реализации и проверки.
Инструкции сами по себе не являются автоматическим CI gate.
