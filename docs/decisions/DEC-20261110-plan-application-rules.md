# DEC-20261110-plan-application-rules: гарантии применения плана

- Связи: [кандидаты](../development/spec-candidates.md), [модель](../development/spec-model.md)

## Решение

1. Повтор одной операции применения возвращает прежний результат без создания дубликата.
2. Уже активный план заменяется только явно; история завершённых тренировок сохраняется.
3. Частичный сбой создания тренировок не отображается как успешное применение.

## Причины и границы

Защищаем от дублирования, неявной замены и ложного успеха. Правила относятся к
применению плана; распространение на остальные операции отдельно обсуждается.
Конкретные альтернативы реализации ещё не выбирались.

## Последствия и проверка

Первое правило о возврате прежнего результата позже заменено
[защитой активного плана](DEC-20261110-simple-active-plan-guard.md). Остальные
договорённости этого решения действуют.

Нужно определить идентичность операции, границу успешного применения и механизм
восстановления после сбоя. Атомарность всех сервисов и автоматический rollback этим
решением не предписаны. Реализация и соответствие существующего кода не проверены.
Будущие specs и тесты должны проверять эти три гарантии. При изменении правил
создать замещающее решение со ссылкой на эту запись.
