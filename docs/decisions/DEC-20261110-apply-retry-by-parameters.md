# DEC-20261110-apply-retry-by-parameters

- Статус: superseded
- Дата: 2026-11-10
- Область: повтор применения плана

- Основание: после обсуждения вариантов выбран вариант «Сравнивать параметры запроса».
- Связи: [контракт](../../openspec/changes/plan-operation-contracts/specs/plan-application/spec.md), [дизайн](../../openspec/changes/plan-operation-contracts/design.md)

## Решение

Для распознавания повтора применения сравнивать параметры запроса. Отдельный ключ
операции, создаваемый клиентом, для этого не требуется.

## Причины и ограничения

Это сохраняет текущую форму клиентского запроса. Однако одинаковые параметры
не содержат сведений о намерении пользователя: случайный retry и намеренное новое
применение с теми же параметрами неразличимы без дополнительного сигнала.
Выбор способа сравнения **не** определяет срок хранения результата, состав
сравниваемых полей, границу между пользователями, реакцию на выполняющуюся операцию
и способ явно начать новое применение с теми же параметрами. Эти решения остаются
открытыми и нужны до реализации AP-1.

## Проверка и пересмотр

После выбора области сравнения проверить повтор sync/async с одинаковыми параметрами,
различие значимых параметров и новый запрос после завершения срока повторения.
Если понадобится отличать два одинаковых намеренных применения, пересмотреть
решение или добавить отдельный явный сигнал.
