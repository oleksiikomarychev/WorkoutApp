# DEC-20261110-simple-active-plan-guard

- Статус: accepted
- Дата: 2026-11-10

- Кем согласовано: владелец проекта в текущем чате

- Заменяет: [сравнение с активным планом](DEC-20261110-active-plan-retry.md)
- Связи: [спецификация](../../openspec/changes/plan-operation-contracts/specs/plan-application/spec.md)

## Решение

Обычный запрос применения при уже активном плане отклоняется без изменения данных.
Для замены требуется явно выраженное намерение. Повторный запрос после успешного
применения поэтому не создаёт второй план, но не обязан возвращать прежний успешный
ответ. Идентификаторы операций, сравнение параметров и журнал результатов не нужны.

## Границы

Это защищает от случайного повторного применения. Намеренная замена остаётся
отдельным действием; её повтор после успеха может снова заменить активный план,
если клиент повторит её без дополнительной защиты. Возможность второго активного
плана не вводится. Гарантия защиты относится также к одновременным обычным запросам:
проверка активного плана и создание нового должны выполняться под одной блокировкой.

Успех только после полного создания обязательных тренировок и сохранение истории
завершённых тренировок по-прежнему обязательны. Это решение их не упрощает.

## Проверка

После первого успешного применения обычный повтор получает отказ, активный план
остаётся прежним и новые тренировки не создаются. Явная замена меняет активный
план, сохраняя завершённую историю. Два одновременных обычных запроса не создают
два активных плана.
